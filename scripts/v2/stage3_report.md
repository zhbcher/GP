## 三、⚠️ 两处关键问题（本阶段发现并修复）

### 3.1 数据污染：1376 只深市股票重复（sh/sz 双前缀）
- 现象：深市股票（000/001/002/003 段）被错误存入 `sh` 前缀的重复记录
- 影响：全市场 580 万行重复，回测中权重翻倍 → **前期年化被虚高**（层8：11.0% → 修复后 5.0%）
- 修复：已删除 `sh` 前缀的深市记录（580 万行），股票数 4569 → **3193 只真实股票**
- 防御：`signals_v2.py` 已加前缀过滤

### 3.2 年化公式错误（52期/年 → 12.5期/年）
- 20 日调仓被按周频（52 期/年）换算年化 → 虚高约 4 倍
- 已修正为 250/20=12.5 期/年
- 影响：层8 年化 54.6%（错误）→ 11.0%（修正）→ 5.0%（数据修复后）
