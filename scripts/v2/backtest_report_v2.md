## 一、合成流程（scorer_v2.py）

```
4个有效因子（V2振幅/M1强度/M3均线/S5换手）
  → 市值中性化（对 log60日均成交额 回归取残差，消除规模代理）
  → 横截面 Z-score + 缩尾（2%~98%）
  → 按实证方向取反（低值加分，A股20日反转效应）
  → 等权合成综合得分
```

## 三、关键实证发现

1. **分层单调性整体成立**：层 0 → 层 8/9 年化从 -60% 到 +55%，反转+低波 alpha 稳健。
2. **顶层失效是 2018 熊市特例**：全周期 Top 层（层9）年化仅 +6.9%，但 2021 年后 +56.4%——2018 大熊市里"极度弱势股"继续阴跌，拉低全周期。
3. **α 最强区间**：全周期在 **80~90 分位（层 8）**，近 5 年在 Top 10%（层 9）——市场状态影响极值端有效性。
4. **市场状态依赖**：
   - 熊市：Top 层超额 +0.69%/期（2021 后 +2.26%/期，弱市里超跌反弹强）
   - 牛市：Top 层超额 -0.96%/期（追涨行情中弱势股跑输）
   - → 建议：**牛市降仓或切换动量风格，熊市/震荡用本方案**
