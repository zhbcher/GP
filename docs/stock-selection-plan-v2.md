# GP 新选股方案设计（v2 独立方案）

> **定位**：与现有"超跌反弹 ML 因子库"（`scripts/factors.py` / `run_signals.py` / `screen.py`）**完全隔离**的
> 一套新选股体系。不改动任何现有文件，新增独立因子集 + 独立打分流程 + 独立回测。
>
> **借鉴来源**（开源调研）：
> - [WAYLON/ashare-quant-strategies](https://github.com/WAYLON/ashare-quant-strategies)：119 篇 A 股策略，多因子/动量轮动/高股息低波/小市值
> - [hugo2046/QuantsPlaybook](https://github.com/hugo2046/QuantsPlaybook)：券商研报复现因子库（聪明钱/特质波动/筹码分布/处置效应/凸显性STR）
> - [微软 Qlib](https://github.com/microsoft/qlib)：Alpha158/Alpha360 结构化因子集
> - [jq-lgbm-quant](https://github.com/0xooank/jq-lgbm-quant)：聚宽 LightGBM 多因子机器学习选股
> - [ellie-mac/stocksage-alpha](https://github.com/ellie-mac/stocksage-alpha)：筹码/热榜/机构/多因子+飞书推送（与 GP 场景高度相似）

## 一、设计理念

现有方案：**单一风格（超跌反弹）× 参数网格 × 模型投票**——在震荡市捕捉超跌反抽，风格集中、相关性高。

新方案：**多风格并列 × 截面因子打分 × 分层组合**——
1. **维度互补**：动量/微观结构/波动率/资金面/价值 五维并列，不同市况总有维度生效
2. **截面选股**：全市场 4569 只股票按因子打分**排名分层**（而非信号触发），可容纳等权/市值加权组合
3. **可归因**：每个因子有 IC、IR、换手等指标，失效可单独淘汰，不拖累全局
4. **独立回测**：walk-forward + 样本外，与现有方案互不干扰

## 二、因子体系（五维 20 因子，全部可用项目已有数据源计算）

> 统一约定：`R_t` = 日收益率，`V_t` = 日成交量(手)，`A_t` = 日成交额(元)，`H/L/O/C` = 最高/最低/开/收。
> 每个因子做 **Z-score 横截面标准化**（全市场当日截面）。

### 维度 1：动量 / 趋势（4 因子）— 参考开源动量研究

| # | 因子 | 定义 | 逻辑 |
|---|------|------|------|
| M1 | **RPS 相对强度** | 20 日涨幅在全市场百分位排名（可另算 60 日） | 识别市场强势股（A股动量核心） |
| M2 | **12-1 月动量** | `(C_t / C_{t-60} - 1) - (C_t / C_{t-20} - 1)`，剔除近 1 月反转 | 经典动量，避开短期反转 |
| M3 | **均线多头排列度** | MA5>MA10>MA20>MA60 的排列程度（加权计分 0~4） | 趋势健康度 |
| M4 | **均线收敛后发散** | 近期均线带宽收敛（波动压缩）后首次向上发散 | 参考开源"均线收敛发散"研报 |

### 维度 2：量价 / 微观结构（5 因子）— 参考开源"聪明钱/上下影线/筹码"研报

| # | 因子 | 定义 | 逻辑 |
|---|------|------|------|
| S1 | **聪明钱因子** | 主动买盘占比：按成交价相对 VWAP 分大单/小单加权（用分时/分钟级数据近似） | 主力行为（开源证券"聪明钱因子"） |
| S2 | **量价相关性** | 过去 20 日 `corr(R_t, V_t)`，负相关为佳（价跌量缩/价升量增） | 高频价量相关性选股 |
| S3 | **上下影线比** | 20 日平均 `(min(open,close)-low) / (high-low)` 与 `(high-max(open,close))/(high-low)` 的差值 | 下影线长=承接强（东吴"上下影线因子"） |
| S4 | **筹码集中度** | 90% 成本区宽度：`(P90 - P10) / P50`（用历史成交量分布近似） | 筹码越集中越易拉升（广发"筹码分布"） |
| S5 | **换手率异动** | 5 日换手率 / 60 日换手率中位数，温和放大为佳（1.5~3 倍） | 关注度上升 |

### 维度 3：波动率（3 因子）— 参考开源"特质波动率/振幅"研报

| # | 因子 | 定义 | 逻辑 |
|---|------|------|------|
| V1 | **特质波动率 IVOL** | 对市场/行业收益回归后的残差波动率（20 日） | 低 IVOL 在 A 股有正溢价（东吴"特质波动率"） |
| V2 | **振幅隐藏结构** | 20 日振幅的截面分位：低振幅+温和放量组合 | 振幅因子的隐藏信息（开源"振幅因子"） |
| V3 | **波动率压缩** | 布林带带宽 `(UB-LB)/MB` 处于近 60 日低分位（<20%） | 突破前兆 |

### 维度 4：资金面（3 因子）— 参考 stocksage-alpha 思路

| # | 因子 | 定义 | 逻辑 |
|---|------|------|------|
| F1 | **主力净流入** | 东财资金流接口：5 日主力净流入 / 流通市值 | 主力态度（eastmoney_source 已内置） |
| F2 | **北向持仓变化** | 沪/深股通持股比例 5 日变化（akshare 可拉） | 外资偏好 |
| F3 | **大宗折溢价** | 近期大宗交易折溢价率（akshare） | 机构定价信号 |

### 维度 5：价值 / 质量（5 因子）— 参考"FFScore/高股息低波"研报

| # | 因子 | 定义 | 逻辑 |
|---|------|------|------|
| Q1 | **FFScore 质量分** | Piotroski F-Score（盈利/杠杆/运营 9 项），A股适配版 | 基本面质量（华泰 FFScore） |
| Q2 | **低估值** | `1/PE` 与 `1/PB` 的截面 Z-score 均值 | 价值因子 |
| Q3 | **高股息** | 股息率 `D/P`（近 12 月分红/市值） | 股息防御 |
| Q4 | **盈利增长** | 归母净利同比增速（TTM） | 成长因子 |
| Q5 | **ROE 稳定性** | 近 4 季 ROE 均值 / 标准差 | 盈利质量 |

## 三、打分与合成（多因子模型）

```
因子值 → 行业/市值中性化 → 横截面 Z-score → 因子 IC 加权合成 → 综合得分
```

1. **中性化**（关键，避免因子成为行业/市值代理）：
   - 对行业哑变量 + log(市值) 回归，取残差
   - 行业数据可从 `info_service`（概念/行业）或 akshare 获取

2. **因子权重**（两档方案）：
   - **静态等权**（简单可靠）：五维各 4 因子等权 → 综合分
   - **IC 加权**（进阶）：用滚动 60 日因子 IC 均值 / ICIR 加权，**因子失效自动降权**（与现有 6 模型融合器同思路）

3. **打分输出**：全市场每日综合得分排名 + 各维度得分（便于归因与 UI 展示）

## 四、组合构建（分层）

- **分层**：按综合分 10 层（十分位），只做 Top 1~2 层（全市场前 10~20%）
- **持仓数**：Top 20~50 只（视资金量）
- **加权**：等权或流通市值加权
- **调仓周期**：周频（5 交易日）或月频，周频适合动量/量价维度，月频适合价值维度；建议**周频为主**
- **行业约束**：单行业持仓 ≤ 30%（避免集中风险）

## 五、风控规则

| 规则 | 实现 |
|------|------|
| 止损 | 单票 -8% 或跌破 20 日线离场 |
| 回撤控制 | 组合回撤 >15% 时降仓 50%，>25% 清仓（进入防御） |
| 流动性过滤 | 剔除日均成交额 < 3000 万、停牌、ST、上市 < 120 日 |
| 涨跌停过滤 | 不追一字板（开盘涨停不买） |
| 换手控制 | 单次调仓换手 ≤ 30%，避免过度交易 |

## 六、回测验证计划

1. **样本**：全市场 4569 只（已含全部主板，数据质量已修复 volume/amount）
2. **区间**：2018-01 ~ 至今（覆盖牛/熊/震荡）
3. **框架**：复用 `scripts/or_backtest.py` 的 walk-forward 骨架，新增独立 `backtest_v2.py`（不碰现有脚本）
4. **指标**：年化收益/最大回撤/Sharpe/Calmar/胜率/换手/IC/ICIR/分层单调性
5. **基准**：沪深 300（与现有超跌方案对比但独立运行）

## 七、交付物清单（全部新增，不修改现有）

```

```
