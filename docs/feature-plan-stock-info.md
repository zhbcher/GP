# 散户看盘系统 · 个股信息 & 市场情绪模块 — 完整方案

> 版本：v1.0 | 日期：2026-07-29 | 状态：待确认

---

## 一、目标

在现有自选股看盘系统（K线 + 实时行情 + 持仓 + 预警）基础上，新增：

1. **个股信息面板** — 选中股票即可查看资讯、公告、研报、财务、资料、资金流向、概念板块、风险提示
2. **市场情绪看板** — 涨停池、北向资金、龙虎榜、板块排行、热度榜
3. **行业资讯**（后续阶段）— 整合 investment-news 的 12 赛道 RSS + AI 提炼

核心定位：**散户在一个界面内完成"看行情 + 看消息 + 看资金 + 看情绪"**，不用切换同花顺/东财/雪球。

## 二、数据源选型

### 首选：a-stock-data（github.com/simonlin1212/a-stock-data）

| 优势 | 说明 |
|------|------|
| 稳定性 | 直连底层 HTTP API，零中间封装（不像 akshare 有版本兼容 bug） |
| 防封设计 | 内置 `em_get()` 限流（串行 ≥1s 间隔 + 随机抖动 + 会话复用） |
| 降级能力 | 每类数据有独立备胎（交易所官方/新浪/同花顺），主源被封不至于瘫痪 |
| 零鉴权 | 除 iwencai 外全部免费无 Key |
| 覆盖全 | 44 端点，行情/研报/信号/资金/新闻/公告/打板/期权/舆情 |
| 与现有系统兼容 | 行情层复用 mootdx + 腾讯（项目已有），只新增信息层 |

### 数据源优先级（沿用 a-stock-data 设计）

| 优先级 | 数据源 | 封IP风险 | 用途 |
|--------|--------|---------|------|
| 1（已有） | mootdx（TCP 7709） | 不封 | K线/五档/财务快照/F10 |
| 2（已有） | 腾讯财经 | 不封 | 实时价/PE/PB/市值/换手率 |
| 3 | 同花顺/巨潮/新浪 | 极低 | 热点/北向/公告/财报三表 |
| 4（限流） | 东财 eastmoney | 有风控 | 龙虎榜/解禁/两融/资金流/研报/新闻/板块 |
| 备用 | 交易所官方/新浪/HKEX | 不封 | 主源被封时降级 |

### akshare 定位：备用

仅在 a-stock-data 对应端点全部失效时，作为最后降级手段。不主动调用。

## 三、功能设计

### 3.1 个股信息面板（右侧面板，Tab 切换）

选中自选股后，右侧面板从"标注面板"扩展为多 Tab 信息面板：

```
┌─────────────────────────────────┐
│ [概览] [资讯] [公告] [研报] [财务] [资料] │  ← Tab 栏
├─────────────────────────────────┤
│                                 │
│  （当前 Tab 内容）               │
│                                 │
└─────────────────────────────────┘
```

#### Tab 1：概览（默认显示）

| 区块 | 数据 | 数据源 | 刷新频率 |
|------|------|--------|---------|
| 估值速览 | PE(TTM)/PB/总市值/流通市值/换手率 | 腾讯（已有） | 实时 |
| 资金流向 | 今日主力/超大/大/中/小单净流入 | 东财 push2 §3.4 | 盘中 5min |
| 概念板块 | 所属概念/行业/地域 + 当日涨跌幅 | 东财 slist §3.3 | 每天 |
| 风险提示 | 未来90天解禁（有则红色警告） | 东财 datacenter §3.6 | 每天 |
| 北向持股 | 沪股通/深股通持股变化（如有） | 同花顺 §3.2 | 盘中 |

#### Tab 2：资讯

| 内容 | 数据源 | 说明 |
|------|--------|------|
| 个股新闻（最新20条） | 东财 search-api §5.1 | 标题+摘要+时间+来源链接 |
| 财联社相关快讯 | 财联社 v1 API §5.2 | 过滤含该股票代码/名称的电报 |

- 默认加载最新 10 条，滚动加载更多
- 新闻按时间倒序，标注来源（东财/财联社）

#### Tab 3：公告

| 内容 | 数据源 | 说明 |
|------|--------|------|
| 公告列表（最新30条） | 巨潮 cninfo §7.1 | 标题+日期+类型+PDF链接 |

- 公告类型标注：定期报告 / 临时公告 / 减持 / 质押 / 业绩预告
- 利空类型（减持/质押/业绩下滑）红色高亮
- 点击可跳转 PDF 原文

#### Tab 4：研报

| 内容 | 数据源 | 说明 |
|------|--------|------|
| 近期研报（最新10篇） | 东财 reportapi §2.1 | 标题+机构+评级+目标价+日期 |
| 一致预期 EPS | 同花顺 §2.2 | 当年/明年/后年 EPS 预测 |
| 估值参考 | 本地计算 | 前向PE / PEG / PE消化年数 |

- 评级用色块：买入(绿) / 增持(蓝) / 中性(灰) / 减持(红)
- 懒加载：点到研报 Tab 才请求

#### Tab 5：财务

| 内容 | 数据源 | 说明 |
|------|--------|------|
| 核心指标（最近4期） | mootdx finance §6.1 | 营收/净利/ROE/毛利率/负债率/EPS |
| 同比变化 | 本地计算 | 标注 ↑↓ 和百分比 |
| 分红历史 | 东财 §4.4 | 每股派息/送股/转增 |

- 只展示关键指标，不做三表全量（散户不需要）
- 懒加载

#### Tab 6：资料（F10）

| 内容 | 数据源 | 说明 |
|------|--------|------|
| 公司简介 | mootdx F10 §6.2 | 主营业务/行业/上市日期 |
| 股本结构 | 东财 push2 §6.3 | 总股本/流通股/十大股东 |
| 股东户数 | 东财 §4.3 | 最近几期变化趋势（筹码集中度） |

- 懒加载
- 低频数据，缓存 7 天

### 4.3 API 接口设计

```
# 个股信息
GET /api/info/{code}/overview       → 概览（资金流+概念+解禁+估值）
GET /api/info/{code}/news           → 个股新闻（?limit=20）
GET /api/info/{code}/announcements  → 公告（?limit=30）
GET /api/info/{code}/reports        → 研报（?limit=10）
GET /api/info/{code}/finance        → 财务核心指标
GET /api/info/{code}/profile        → F10 资料
GET /api/info/{code}/capital-flow   → 资金流向（分时+120日）

# 市场情绪
GET /api/market/limit-up            → 涨停池/炸板/跌停
GET /api/market/north-flow          → 北向资金
GET /api/market/dragon-tiger        → 龙虎榜（?date=YYYY-MM-DD）
GET /api/market/sectors             → 板块排行+资金流
GET /api/market/hot-rank            → 热度榜

# 通用
POST /api/info/refresh              → 手动触发刷新
```

### 4.5 东财防封策略

严格遵循 a-stock-data 的防封铁律：

1. **所有东财请求走 `em_get()`**：串行限流，最小间隔 1s + 随机抖动
2. **绝不并发**：东财请求全部串行，用 asyncio.Lock 保证
3. **会话复用**：全局 httpx.AsyncClient（Keep-Alive）
4. **正常 UA + Referer**
5. **批量场景降频**：自选股数量 > 10 时，间隔调大到 1.5s
6. **被封降级**：检测 403/429/连接重置 → 自动切换备用源

### 4.6 定时任务

| 任务 | 时间 | 内容 |
|------|------|------|
| 盘前刷新 | 09:00 | 解禁/公告/研报/概念归属 |
| 盘中刷新 | 09:30-15:00 每5min | 资金流向/北向（仅自选股） |
| 盘中刷新 | 09:30-15:00 每10min | 涨停池/板块排行 |
| 盘后刷新 | 16:00 | 龙虎榜/热度榜/新闻汇总 |
| 周刷新 | 周六 10:00 | 财务/F10/股东户数 |
